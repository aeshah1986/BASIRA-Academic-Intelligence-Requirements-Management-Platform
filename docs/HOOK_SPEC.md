# Hook الحماية: البيانات الحقيقية وبيانات الفحص والنشر

> **الحالة (2026-10-31): مُفعّل في المشروع.** الإعداد في `.claude/settings.json`، والسكربت `.claude/hooks/guard.js`، والفحوص `tests/hook-guard.test.js` (HOOK-01..04).
> قبله كانت الحماية **توجيهًا** في `CLAUDE.md` فقط، يعتمد على التزام النموذج.

## الفرق بين التوجيه والإنفاذ
| | التوجيه (`CLAUDE.md`) | الإنفاذ (Hook) |
|---|---|---|
| الآلية | تعليمات يقرؤها Claude ويلتزم بها | سكربت ينفذه Claude Code قبل الأداة، ويمنعها مهما كانت التعليمات |
| عند الخطأ | يعتمد على التزام النموذج | تُرفض العملية برسالة |

## القواعد
| # | الحدث | الشرط | القرار |
|---|---|---|---|
| 1 | `Write`، و`Edit`، و`MultiEdit`، و`NotebookEdit` | المسار داخل `C:\Users\User\Desktop\ملف التصنيفات العربية\`، بأي صيغة (`\` أو `/` أو `/c/`) | **منع** (رمز 2): «هذا المجلد مرجع للقراءة فقط وفيه بيانات حقيقية» |
| 1ب | `Bash` و`PowerShell` | الأمر يذكر المجلد **و**فيه عملية كتابة أو حذف أو نقل (`>`، و`rm`، و`mv`، و`cp`، و`Set-Content`، و`Remove-Item`…) | **منع** (رمز 2) |
| 2 | أدوات الملفات | `data/sample-data.js` | **طلب تأكيد** (`ask`)، لأن حالات القبول مبنية عليه |
| 3 | `Bash` و`PowerShell` | `git push` | **طلب تأكيد** (`ask`): لا نشر دون موافقة لكل مرة |

- القراءة من المجلد الحقيقي (`Read`، و`ls`، و`Get-ChildItem`) تمر، لأن قراءة المنهجية ورؤوس النماذج مسموحة.
- **الصلاحيات:** السكربت يقرأ stdin فقط، ولا يكتب ملفات، ولا يتصل بالشبكة، ووحدات Node المدمجة فقط.

## الإعداد (`.claude/settings.json`)
```json
{ "hooks": { "PreToolUse": [ { "matcher": "Write|Edit|MultiEdit|NotebookEdit|Bash|PowerShell",
  "hooks": [ { "type": "command", "command": "node \"$CLAUDE_PROJECT_DIR/.claude/hooks/guard.js\"", "timeout": 10 } ] } ] } }
```

## الحدود
- **التفعيل:** يقرأ Claude Code الـ Hooks عند بدء الجلسة. أُضيف الإعداد أثناء جلسة قائمة، فلم يعمل فيها، وجُرب فيها بمحاكاة الأمر نفسه. يظهر أثره في أي جلسة جديدة تُفتح على مجلد `BASIRA`.
- **قاعدة الأوامر تقريبية:** تبحث عن ذكر المجلد مع عملية كتابة. قد تمنع أمر قراءة يذكر المجلد مع `cp` منه، وذلك مقبول لأن الخطأ في اتجاه الحماية. ولا تكشف أمرًا يبني المسار من متغيرات.
