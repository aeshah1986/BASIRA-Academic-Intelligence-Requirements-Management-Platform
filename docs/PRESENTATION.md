# ملخص عرض المشروع أمام المقيّمة (10–12 دقيقة)

## 1. المشكلة (دقيقة)
- مكاتب التصنيفات الجامعية تجمع بيانات عشرات المؤشرات من جهات متعددة قبل موعد تسليم صارم.
- الواقع: نواقص لا يُعرف من يملكها، ومواعيد تفوت دون أن يلاحظ أحد، وأرقام متعارضة بين المصادر، وجهات لا ترد، وأسئلة تنتظر قرارًا.
- **«بصيرة»** منصة محلية بالعربية تجعل ذلك كله مرئيًا ومتابَعًا.

## 2. القيود التي التزمنا بها (30 ثانية)
- ملف `index.html` واحد يعمل دون خادم ولا إنترنت ولا حساب ولا خدمة مدفوعة.
- العربية RTL، والجوال.
- بيانات وهمية فقط: البيانات الحقيقية قُرئت بنيتها فقط، وفحص آلي يمنع تسربها.
