# 05 — التصور البصري، ودعم العربية RTL، والتكيف مع الجوال

> وثيقة تصميم. النماذج البصرية: [mockups/dashboard-desktop.svg](mockups/dashboard-desktop.svg) و[mockups/mobile.svg](mockups/mobile.svg) (تُفتح في المتصفح).

## 1. الهوية: أبيض · كحلي · تركواز

**المبدأ:** الأبيض مساحة العمل، والكحلي للهيكل والعناوين والأزرار الأساسية (الثقة والرسمية)، والتركواز للتمييز والحالة النشطة والروابط (حيوية دون إزعاج). ألوان الحالة (أحمر، كهرماني، أخضر) خافتة، **وترافقها دائمًا كلمة**، فلا يُعتمد على اللون وحده.

### 1.3 الخطوط والأحجام
- **عائلة الخطوط** (مثبتة على الجهاز دون إنترنت): `"Segoe UI", Tahoma, "Noto Naskh Arabic", "Geeza Pro", Arial, sans-serif`. لا خطوط من الإنترنت (CLAUDE.md).
- **السلم:** عنوان الصفحة 24px/700 · عنوان القسم 18px/700 · النص 16px/400 · الصغير 14px · الأدنى 13px للتسميات الثانوية فقط. **لا نص أصغر من 13px.**
- **ارتفاع السطر:** 1.7 للنص العربي (أعلى من اللاتيني، لاستيعاب النقاط والحركات).
- **الأرقام:** لاتينية (0–9) عبر `ar-u-ca-gregory-nu-latn`.

### 1.4 المسافات والأشكال
- **شبكة 8px:** المسافات 4 / 8 / 12 / 16 / 24 / 32.
- **حواف البطاقات:** 12px. **الأزرار والحقول:** 8px. **الشارات:** 999px (كبسولة).
- **الظل:** واحد خفيف للبطاقات `0 1px 3px rgba(11,31,58,.08)`. لا ظلال ثقيلة ولا تدرجات.

### 1.5 المكونات

| المكون | الشكل |
|---|---|
| الزر الأساسي | خلفية `navy-700`، ونص أبيض، وارتفاع 44px، وحافة 8px |
| الزر الثانوي | حد `turq-700` 1.5px، ونص `turq-700`، وخلفية بيضاء |
| زر الخطر | خلفية `danger`، ونص أبيض. يظهر فقط داخل حوار التأكيد |
| الحقل | ارتفاع 44px، وحد `border-input`، وعند التركيز حلقة `turq-700` بسماكة 2px وإزاحة 2px. وعند الخطأ حد `danger` ورسالة تحته بالأحمر مع ⚠ |
| الشارة | كبسولة بخلفية فاتحة ونص داكن **وكلمة دائمًا**: «متأخر 12 يومًا»، «قريب: 4 أيام»، «مكتمل»، «تعارض» |
| بطاقة التصنيف | شريط تركواز بعرض 4px على **الحافة اليمنى**، والعنوان، والعد التنازلي كبيرًا، وشريطا تقدم (المتطلبات، والجاهزية) مع النسبة كنص |
| بطاقة KPI | الرقم 32px/700 بالكحلي، والتسمية تحته، وتكون رابطًا بالكامل |
| الجدول | رأس `navy-100`، وصفوف بارتفاع ≥ 48px، وتظليل الصف عند التمرير `turq-100`، والصف كاملًا قابل للنقر (مع رابط حقيقي في عمود العنوان للوحة المفاتيح) |
| الحالة الفارغة | أيقونة خطية تركواز، وجملة، وزر إجراء واحد |

### 1.6 الأيقونات
SVG خطية مضمنة في الصفحة (لا مكتبات)، بسماكة 1.75px و`currentColor`. **تُعكس في RTL فقط الأيقونات الاتجاهية** (أسهم «التالي/السابق»، و«رجوع»). أيقونات مثل البحث والتقويم والطباعة لا تُعكس.

## 2. دعم العربية RTL

| البند | القرار |
|---|---|
| الوثيقة | `<html lang="ar" dir="rtl">` |
| التخطيط | خصائص CSS منطقية فقط: `margin-inline-start`، `padding-inline-end`، `inset-inline-start`، `text-align: start`، وليس left/right، ليصح التخطيط تلقائيًا |
| التنقل | الشريط الجانبي على **اليمين**، وتسلسل المسار (المؤشرات ‹ AR-EDU-1) يُقرأ من اليمين، والسهم `‹` معكوس |
| **القيم المختلطة** | القيم والرموز والروابط داخل `<bdi>` أو `<span dir="ltr">`: النسب **«1:15»** (بدونها قد تظهر «15:1» فيُقرأ المعنى معكوسًا، وهو خطأ جوهري في مؤشر الأعضاء إلى الطلبة)، و`AR-EDU-1`، والروابط، والتواريخ الرقمية |
| التواريخ | تُخزن `YYYY-MM-DD`، وتُعرض «1 نوفمبر 2026» بـ `Intl.DateTimeFormat('ar-u-ca-gregory-nu-latn')`. **تنبيه:** `ar-SA` وحدها تعرض التاريخ **الهجري**، فيجب ذكر `ca-gregory` صراحة |
| الأرقام | لاتينية في كل الواجهة، مثل منصة التصنيف وملفات Excel، مع فاصل آلاف `,` |
| النسب المئوية | «11%» داخل `dir="ltr"` |
| حقول الإدخال | العربية `dir="auto"` (يتكيف حسب أول حرف). الرابط والرمز `dir="ltr"` |
| CSV | ترميز UTF-8 مع BOM، فيفتح Excel العربية صحيحة |
| الطباعة | النسق نفسه RTL، ويُخفى التنقل والأزرار، والجداول بحدود رفيعة، و`@page { margin: 15mm }` |
| النصوص | فصحى مختصرة بصيغة الأمر للأزرار («إضافة متطلب»، «حفظ»)، ورسائل خطأ تقول ما المشكلة وكيف تُحل |

## 3. التكيف مع الجوال

| العرض | التغيير |
|---|---|
| **≥ 1024px** | شريط جانبي 240px يمينًا، ولوحة القيادة: صف بطاقات التصنيف (2) ثم صف KPI (5) ثم عمودان («يحتاج انتباهك» 60%، و«التعارضات» و«الأسئلة» 40%) |
| **640–1023px** | شريط جانبي أيقونات 72px، وKPI في شبكة 3 + 2، وعمود واحد للأقسام |
| **< 640px** | شريط سفلي ثابت (64px + المنطقة الآمنة)، وبطاقات التصنيف مكدسة، وKPI شبكة 2 × 3 (الخلية السادسة «إضافة متطلب»)، و**الجداول تتحول إلى بطاقات** (العنوان، والشارات، وسطر «المؤشر · الجهة»)، والتصفيات داخل لوحة منبثقة من زر «تصفية (n)» |
| **كل الأحجام** | أهداف اللمس ≥ 44 × 44px، و`max-width: 100%` للصور والجداول، و**لا تمرير أفقي عند 375px** (AC-UI-04)، والنص لا يُقص بل يلتف، ويدعم تكبير المتصفح حتى 200% |

## 4. ما لن نفعله (عمدًا)
- لا وضع داكن في هذه النسخة، لضيق الوقت. الرموز معدّة بحيث يمكن إضافته لاحقًا.
- لا رسوم بيانية بمكتبات، فأشرطة التقدم بـ CSS فقط ومعها النسبة كنص.
- لا حركات ولا انتقالات سوى تلاشي الرسائل 150ms، مع احترام `prefers-reduced-motion`.
