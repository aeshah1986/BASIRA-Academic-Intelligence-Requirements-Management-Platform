# مصدر المتطلبات المحلي (بديل MCP، اليوم الرابع من الدورة)

لا يتصل المشروع بأي خادم MCP أو نظام جامعي، وهذا مقصود: البيانات حساسة، والتشغيل محلي. بدلًا من ذلك، هذه هي المصادر المحلية التي يقرؤها Claude كمرجع للمتطلبات:

| المصدر | ما يحتويه | من يحدّثه |
|---|---|---|
| `ACCEPTANCE_CRITERIA.md` | 156 حالة قبول مرقمة بالمتوقع وطريقة الفحص | تُضاف الحالات مع موافقة المستخدمة |
| `docs/design/01–09` | الصفحات، والتنقل، والبيانات، والقواعد R-… والحسابات C-…، والتصاميم المعتمدة | يُعتمد كل تصميم قبل تنفيذه |
| `PROJECT_PLAN.md` §3 و§10 | متطلبات الدورة، والمعايير، والتعارضات المفتوحة G1–G14 | عند كل قرار |
| `data/sample-data.js` | سجلات الفحص F1–F6 التي تُبنى عليها الأرقام المتوقعة | لا يُعدل إلا بطلب صريح |

**لو رُبط MCP مستقبلًا** (مثل منصة اتحاد الجامعات العربية أو نظام الموارد البشرية)، فيجب أن يكون بصلاحية قراءة فقط، ودون نقل بيانات شخصية إلى المنصة. وهذا خارج نطاق المشروع الحالي.
